Глава 1. Git и GitHub

Git работает локально на компьютере разработчика, GitHub хранит копию
репозитория в сети. Связь между ними обеспечивает remote с именем origin.

Основные операции: clone — получить копию репозитория, commit — зафиксировать
изменения, push — отправить их на GitHub, pull — получить чужие изменения.
