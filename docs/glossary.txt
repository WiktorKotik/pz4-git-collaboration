Глоссарий

Репозиторий - хранилище проекта и его истории.
Коммит      - зафиксированное состояние проекта.
Индекс      - область подготовки изменений перед коммитом.
Ветка       - независимая линия разработки.
Remote      - сетевой репозиторий (origin).
Push / Pull - отправка и получение изменений.
Fork        - собственная копия чужого репозитория.
