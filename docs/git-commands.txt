Основные команды Git

git init              - создать локальный репозиторий
git clone <url>       - скопировать сетевой репозиторий
git status            - состояние рабочей папки
git add <файл>        - добавить файл в индекс
git commit -m "text"  - зафиксировать изменения

Работа с ветками

git branch                 - список веток
git checkout -b <ветка>    - создать ветку и перейти в неё
git merge <ветка>          - влить ветку в текущую
