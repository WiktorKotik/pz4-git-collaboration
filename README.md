# Практическое занятие 4: приватный репозиторий и совместная работа

Учебный репозиторий по МДК.01.03 «Разработка мобильных приложений»
(специальность 09.02.07 «Информационные системы и программирование»).

**Автор:** Шумейко Виктор

## Назначение

Репозиторий создан для освоения основных приёмов работы с Git и GitHub:
создание сетевого репозитория, добавление файлов, ветвление, клонирование
и совместная работа с другими участниками.

## Содержимое основной ветки

| Файл | Описание |
|------|----------|
| `README.md` | Описание репозитория |
| `notes.txt` | Текстовые заметки о Git |
| `git-cheatsheet.pdf` | Шпаргалка по командам Git |
| `branches-scheme.png` | Схема веток репозитория |

## Ветки

| Ветка | Содержание | Файлов в ветке | Коммитов в ветке |
|-------|-----------|:--------------:|:----------------:|
| `docs/git-theory` | Конспекты: команды Git и глоссарий | 6 | 4 |
| `feature/android-login-screen` | Экран авторизации Android-приложения | 7 | 6 |
| `assets/images` | Изображения и схемы | 8 | 5 |
| `release/v1.0-report` | Текстовый отчёт по работе | 9 | 8 |

В столбце «Файлов в ветке» учтены файлы основной ветки, в столбце «Коммитов»
указано число коммитов, сделанных именно в этой ветке.

## Как получить локальную копию

```
git clone https://github.com/WiktorKotik/pz4-git-collaboration.git
```

Переключение на нужную ветку:

```
git checkout docs/git-theory
```
