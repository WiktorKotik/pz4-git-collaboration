Заметки о системе контроля версий Git

Git — распределённая система контроля версий. Она хранит историю изменений
файлов проекта и позволяет возвращаться к любой сохранённой версии.

Основные понятия:
- репозиторий — хранилище проекта вместе с историей изменений;
- коммит — зафиксированный набор изменений с сообщением;
- ветка — независимая линия разработки;
- remote (origin) — сетевой репозиторий, например на GitHub.

GitHub — веб-сервис для хранения репозиториев и совместной работы.
Приватный репозиторий виден только владельцу и приглашённым участникам.
